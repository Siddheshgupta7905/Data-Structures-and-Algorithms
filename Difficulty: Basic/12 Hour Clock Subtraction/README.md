<h2><a href="https://www.geeksforgeeks.org/problems/12-hour-clock-subtraction1708/1">12 Hour Clock Subtraction</a></h2><h3>Difficulty Level : Difficulty: Basic</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 14pt;">Given two integers <strong>x </strong>and <strong>y</strong>, subtract num2 from num1 on a 12-hour clock. Return the resulting hour in the range 0 to 11.</span></p>
<p><span style="font-size: 14pt;">&nbsp;<strong>Note:</strong> Assume the clock is numbered from 0 to 11.</span></p>
<p><span style="font-size: 14pt;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 14pt;"><strong>Input</strong>: x = 7, y = 5
<strong>Output: </strong>2
<strong>Explanation: </strong>7 - 5 = 2, so the result on the 12-hour clock is 2.</span></pre>
<pre><span style="font-size: 14pt;"><strong>Input</strong>: x =<strong> </strong>5, y = 7
<strong>Output: </strong>10
<strong>Explanation: </strong>5 - 7 = -2. On a 12-hour clock, -2 corresponds to 10.</span></pre>
